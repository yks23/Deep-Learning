## 实验1
TA觉得深度学习很神奇，但有人告诉TA，深度学习就像炼丹，要训练好深度学习的模型是一件很玄的事
情，因为深度学习有很多超参数要调。TA不相信，决定自己动手试试。你也一起来试试吧。

目标：通过交互式工具熟悉神经网络的基本概念与常见超参数对训练行为的影响（例如学习率、层数、正则化等）。本实验以“玩”和“观察”为主，重在理解而非工程实现。

快速一键指引（在浏览器中完成）：

1. 打开 Neural Network Playground：

	https://playground.tensorflow.org/

2. 建议的操作流程：
	- 选择不同的数据集，逐项查看页面上每个控制项（activation、learning rate、regularization、noise、hidden layers 等）的注释与可视化效果；
	- 先把任务设为默认分类任务，然后切换到“最后一个分类任务（双螺旋线）”；将 Ratio of training to test data 设为 70%，Noise 设为 40%；
	- 在双螺旋数据上调整学习率、层数、每层神经元数目和正则化方式，观察训练曲线与决策边界的变化。

思考要点（提交报告时可覆盖这些问题）：
 - 在本任务中，哪些超参数对收敛速度影响最大？为什么？
 - 学习率过大或过小时观察到的行为分别是什么？如何平衡收敛速度与稳定性？
 - 小模型与大模型在这个数据集上的表现差异是什么？过拟合/欠拟合如何识别？
 - 噪声（Noise）增加时，网络表现的变化与可能的对策（例如正则化、数据扩增）是什么？
